Install klavyn

macOS and Linux. One line to start; cargo or source if you'd rather.

$ curl -fsSL https://klavyn.app/install.sh | sh

Prefer to read it first? View install.sh before piping to a shell — always a good habit.

Package managers

Install from source with Cargo (Rust's package manager). Until tagged binary releases land, this builds the latest from the repository:

$ cargo install --git https://github.com/klavyn/klavyn klavyn

The one-line installer above does this for you automatically when no prebuilt binary matches your platform.

Build from source

$ git clone https://github.com/klavyn/klavyn
$ cd klavyn
$ cargo build --release
$ ./target/release/klavyn --quiet

Platform notes

macOS

klavyn asks for two permissions the first time you run it (System Settings → Privacy & Security): Input Monitoring (to see key presses) and Accessibility (to inject the backspace/retype correction). Accessibility isn't needed in --dry-run mode.

Linux

The global-input backend targets X11. You'll need the X11 development libraries at build time (Debian/Ubuntu: libxi-dev libxtst-dev libx11-dev) and either membership in the input group or matching udev rules for raw input access. Wayland sessions are a known weak spot for this whole category of tool.

Heads up

klavyn is, mechanically, a global keyboard listener — chording can't work any other way. It makes no network calls and writes nothing you type to disk. Read SECURITY.md and verify each claim before you trust it.
