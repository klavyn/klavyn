What klavyn does, how to run it, and how it recognizes a chord.

klavyn is a QWERTY chorded-typing trainer. Press the letters of a word at once — in any order — and it replaces what you typed with the whole word. It approximates a CharaChorder in software, on ordinary hardware.

# Install

$ curl -fsSL https://klavyn.app/install.sh | sh

See Download for Cargo, building from source, and per-platform permission notes.

# Running klavyn

$ klavyn --quiet
klavyn: loaded 4112 chords from "data/dictionary.en.csv"
klavyn: listening globally (roll gap 200ms). Ctrl+C to quit.
klavyn: chord "klo" -> "look"

Common flags:

FlagWhat it does
--dry-runRecognize and log chords without injecting corrections. Safe first run.
--roll-gap-ms <n>Max idle gap between rolled keypresses (default 200). Lower = stricter.
--quietOnly log matched chords, not every keystroke event.

# How it recognizes a chord

klavyn listens globally for key presses (via rdev) and matches a chord two ways:

  • Held together — press several letters at once, then release them.
  • Arpeggiated / rolled — press and release letters one at a time (or a couple at once), as long as each new press starts within --roll-gap-ms of the keyboard last going idle.

Once the chord's letters are known, klavyn looks them up in its dictionary and, on a match, backspaces what you literally typed and types the matched word instead (via enigo).

Rolling is what makes long words work on ordinary keyboards. Your keyboard's simultaneous-key ceiling (often 6 on non-NKRO boards) only limits how many keys you can hold at one instant — rolling never asks for more than that.

# Measuring your keyboard

$ klavyn detect-rollover

Hold as many different letter keys as you can for a few seconds; klavyn reports the maximum it actually saw end-to-end. Purely informational — it tells you which words you'll want to roll rather than hold. See Learn → rollover for what the number means.

# Letter-set collisions

Because a chord is an unordered set of letters, some words share one — {a,e,r} is are, ear, and era. Each per-language dictionary resolves every collision by keeping only the highest-frequency word for that letter set, so a chord is always unambiguous.

# A known v1 limitation

klavyn lets your OS type the individual letters normally, then corrects them after the fact (backspace + retype), the same way autocorrect works. Genuinely fast sequential typing that lands within the roll-gap window can occasionally get "corrected" into a chord you didn't intend — that's the --roll-gap-ms knob to tune. True keystroke suppression is a possible v2.

# Configuration (in progress)

Dictionaries ship as per-language CSVs, with a community-extensible abbreviation tier layered on top. A TOML config format (.klavyn.toml project-local, with an optional global ~/.config/klavyn/config.toml) is on the roadmap. Follow docs/roadmap.md for status.
